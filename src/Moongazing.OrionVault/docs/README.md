# Moongazing.OrionVault

Core package: AES-256-GCM column encryption primitives, in-config static key provider, telemetry, and the bundled Roslyn analyzer.

To use with EF Core, also install `Moongazing.OrionVault.EntityFrameworkCore`.

For full documentation, quickstart, and the threat model see https://github.com/tunahanaliozturk/OrionVault.
